# Impeccable Design Context — Otragenie Camp

## Design Context

### Users

Предприниматели 35–50, выгоревшие женщины, пары в кризисе, успешные люди, потерявшие смысл. Человек приходит на сайт в момент внутреннего напряжения: что-то перестало работать, привычные инструменты исчерпаны. Он не ищет мотивацию — он ищет настоящее. Контекст просмотра: вечер, телефон или ноутбук, усталость, скептицизм (видел много подобных предложений). Работа сайта — за первые 10 секунд дать ощущение: здесь не продают, здесь предлагают что-то настоящее.

### Brand Personality

Три слова: **медленный / весомый / настоящий**

- *Медленный* — не спешит, не давит, не кричит. Пространство между элементами — не пустота, а воздух для дыхания.
- *Весомый* — слова и образы имеют вес. Ничего легковесного, ничего случайного. Каждая деталь заработана.
- *Настоящий* — полная противоположность инфоциганству. Никаких "осталось 3 места", обратных отсчётов, фейковых отзывов с фото из стоков. Авторы — реальные люди с реальным опытом.

Эмоциональная цель: человек, закрывая сайт, должен почувствовать, что **состояние ресурса уже началось**. Сам процесс просмотра — маленькая доза того, что предлагает кэмп: тишина, честность, пространство.

### Aesthetic Direction

**Тема**: тёмный hero (navy #0b1130) → кремовый контент (#f3ede4). Это правильно и остаётся.

**Палитра (обновлено 2026-04-28)**: переведена на OKLCH для перцептивной однородности. Земляные тона сохранены.
```
--color-cream:          oklch(95.2% 0.012 72)   /* фон светлых секций */
--color-cream-soft:     oklch(92.8% 0.016 72)   /* Program */
--color-cream-card:     oklch(98.5% 0.005 72)   /* карточки, модалки */
--color-cream-card-alt: oklch(96.4% 0.010 72)   /* Pricing фон */
--color-navy:           oklch(18.5% 0.038 264)  /* тёмные секции */
--color-brown:          oklch(56.4% 0.072 52)   /* основной акцент */
--color-brown-light:    oklch(63.8% 0.076 54)   /* акцент на тёмном */
--color-text-dark:      oklch(22.5% 0.018 52)   /* основной текст */
--color-text-dark-soft: oklch(40.5% 0.028 50)   /* второстепенный текст */
```

**Анимации (обновлено 2026-04-28)**: воздушные, медленные. `duration: 1.1s`, easing `[0.16, 1, 0.3, 1]`, смещение 22px + `blur(2px)→blur(0)`. Ощущение всплытия, не скачка.

**Типографика (обновлено 2026-04-28)**: шрифты заменены.
- Заголовки и UI-текст: **Geologica** — humanist sans, широкие пропорции, уверенный, не шаблонный. `font-weight: 600`, `letter-spacing: -0.02em` для заголовков.
- Цитаты, акцентные фрагменты, `.font-serif`: **Young Serif** — антиква с характером, органичная. Не в списке запрещённых рефлексов.
- `h1–h6` рендерятся через Geologica (не serif-класс), `.font-serif` — через Young Serif.

**Антиреференс**: инфоциганство — значит, НЕТ:
- countdown-таймерам и "осталось X мест"
- стоковым фотографиям счастливых людей
- длинным буллет-листам "вы получите..."
- жёлтым кнопкам "ЗАПИСАТЬСЯ СЕЙЧАС!!!"
- testimonials-каруселям с аватарками из стоков
- glassmorphism везде как попытке выглядеть "дорого"

**Что должно быть**: пространство, тишина, конкретные авторы с реальными историями, текст который звучит как живой человек, а не продающий копирайтер.

### Design Principles

1. **Тишина — это дизайн-решение.** White space не пустота — это воздух. Сайт должен дышать медленнее, чем большинство коммерческих лендингов.

2. **Никакого давления, никогда.** Отсутствие манипулятивных паттернов — само по себе сигнал качества для скептичной аудитории. Urgency theater убивает доверие.

3. **Земля, не абстракция.** Палитра, образы, язык — всё должно быть заземлённым. Лес, глэмпинг, горы Красной Поляны. Не "путь к себе" в облаках, а конкретное место в конкретные даты.

4. **Авторы как якорь.** Майя и Роман — главный аргумент. Их реальность, экспертиза и человечность должны быть ощутимы, не задекларированы.

5. **Сайт — первая сессия.** Каждый экран должен давать маленькое облегчение: "кто-то это понимает". Не убеждать, а резонировать.

---

### Hard Constraints

- **Тексты не трогать** — любые правки касаются только вёрстки, визуального дизайна, отступов, шрифтовых размеров, цветов, анимаций. Копирайт заморожен.
